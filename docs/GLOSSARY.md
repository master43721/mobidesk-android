# MobiDesk Glossary

| Term | Meaning |
|---|---|
| Assignment | Trusted server-side relationship between one authenticated student and an approved VM |
| Broker | Server-side authorization, status and RDP relay service; not a Windows identity provider |
| Grant | Short-lived, random, one-use authorization token bound to user, session and assigned VM |
| NLA | Network Level Authentication used by Windows RDP before desktop session establishment |
| RDP | Remote Desktop Protocol |
| RDP readiness | Evidence that assigned guest RDP is ready; a TCP port probe alone is reachability |
| RLS | Supabase Row Level Security restricting records to the authenticated subject |
| RdpSessionActivity | Native Android Activity that owns FreeRDP session rendering/input boundary |
| WSS | WebSocket Secure; proposed RDP byte relay, not synonymous with RD Gateway |
| VM lifecycle | Hypervisor/guest power state such as STOPPED, STARTING or RUNNING |
| FLAG_SECURE | Android window flag that blocks normal screenshots and recent-task previews |
| AOA | Android Open Accessory; USB descriptors are discovery hints, not cryptographic identity |
